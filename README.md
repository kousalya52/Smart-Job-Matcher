# Smart Job Matcher

A web-based resume analysis and job matching application that helps
job seekers evaluate their resume against job requirements.

## Features

- Resume upload
- PDF/DOCX/TXT support
- Skill extraction
- Job matching
- Weighted skill matching
- ATS score
- Missing skill detection
- Job role ranking
- Learning roadmap
- Custom job description analysis

## Technologies

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Python
- Flask

Libraries:
- pypdf
- python-docx

## How It Works

Resume
   ↓
Text Extraction
   ↓
Skill Extraction
   ↓
Job Requirement Analysis
   ↓
Weighted Matching
   ↓
ATS Analysis
   ↓
Results
